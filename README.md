# 📉 Análise de Gastos

Um projeto simples em Python para analisar gastos mensais.  

## 🛠 Tecnologias usadas  
- Python 3  
- Pandas (análise de dados)  
- Matplotlib (visualização)  

## 📌 Como usar  
1. Edite gastos.csv com seus gastos.  
2. Execute o script:  
   ```bash  
   python analise_gastos.py
